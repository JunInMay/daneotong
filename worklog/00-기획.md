# 기획

> 원본: Obsidian `정보/기획/기획(다너통, 프로젝트).md`

- **이름**: 다너통 (단어 + 통)
- **철학**: 모르는 표현을 만났을 때 빠르게 저장하고 빠르게 복습한다 — 신속이 핵심.
- **커버리지**: 단어뿐 아니라 숙어/구동사 등 여러 단어로 구성된 표현까지. 처음엔 웹앱, 이후 네이티브 앱 고려.
- **타겟**: 영어 → 한국어 (개발자 본인이 최초 유저).
- **핵심 기능**: 단어 저장(사전 검색 연동), 목록 조회(검색 포함), 플래시카드 복습.
- **외부 API**: 사전 검색(한국어: 네이버 사전, 영어: 무료 사전 API). CORS 문제로 프론트 직접 호출 불가 → 백엔드에서 처리.
- **스택**: 프론트 React / 백엔드 Spring Boot / 인증 Spring Security / DB PostgreSQL(클라우드 예정).
